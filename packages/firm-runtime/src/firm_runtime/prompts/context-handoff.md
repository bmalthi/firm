Save durable work to the drive and call `handoff(notes, next="continue"|"wait")` with
short notes about unfinished work and where to find its current state. Useful examples
include delegated work and awaited results, answers awaited, commitments and deadlines,
decisions and their reasoning, durable or needed `scratch` paths, and the next action.
Omit finished or discarded work; point to durable material instead of copying it. Files
and mail survive; conversation memory is not carried into a fresh work period, and
Operations does not reconstruct unresolved work. Read mail is no longer unread; keep its
message ID if you still need it.

Both `continue` and `wait` replace conversation memory with fresh working memory when
this work period finishes. Choose `continue` to request another work period, or `wait`
for new input to wake you. Once handoff confirms your notes are saved, end your response
without further tool calls.
