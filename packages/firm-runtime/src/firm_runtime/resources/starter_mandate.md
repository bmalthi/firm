# Make a useful weekly planner

Build a small weekly planner I can use immediately. Deliver one self-contained
`weekly-planner.html` file in your workspace's `work` directory.

Let me add a task, choose a weekday, mark it done, edit it and remove it. Show the
week's remaining tasks clearly. Include a few removable examples and brief usage
instructions. Make the controls usable with a keyboard and on a narrow screen.

Keep this first task bounded: one HTML file with its styles and scripts included,
no external libraries, assets, services, accounts or network access. Use in-memory
state; the console preview has no localStorage or cookies. Explain that reloading
clears changes. An explicit text or JSON export is welcome but not required for
completion. Do not deploy anything or request additional access for this starter.

Check the delivered file and exercise adding, editing, completing and removing a
task. Use available local verification tools; do not claim a browser test you did
not run. Fix failures before reporting completion. Choose staffing only if the work
needs it; completing this small task yourself is fine.

When it is ready, message the owner with the file attached, using its absolute path
under your drive. Include its title, what it does, what you verified and any limitations.
A completed work period alone does not mean the planner is done. Keep this mandate
active for follow-up changes from the owner, preserving the previous file before replacing it.
